# Test plan

Run `python3 self_test.py` for the unit/socket suite and `python3 -m tests.gui_smoke` for the opt-in desktop flow. Windows uses `py -3` instead of `python3`.

The complete physical acceptance checklist, expected results, hotspot instructions and troubleshooting are in [RUN_AND_TEST.md](../RUN_AND_TEST.md). Observed local results and limitations are in [TEST_RESULTS.md](../TEST_RESULTS.md).

Before presenting, use **Standard · 2 rounds** on two actual computers, complete a non-draw match, verify both-vote winner-first rematch, reset after earning a point, disconnect/rejoin, and check the exact network to be used. Demonstrate extended matches and AI separately from the required base game.
