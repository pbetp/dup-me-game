# Demo script

Use the [short demo sequence and professor Q&A](professor-notes.md). Run steps for integrated and separate-server setups are in [RUN_AND_TEST.md](../RUN_AND_TEST.md).

The required setup is two physical computers: A runs server plus client; B runs only a client. In integrated mode A selects Host and play and B selects Join. In separate-process mode A starts server.py and both player windows select Join. Players use discovery or a host-exported connection file; neither needs to type an IP/port.

Demonstrate Standard first: welcome, count/list, pattern visibility, timer, positional scoring, role swap, results, rematch and reset. Then show optional features. Avoid claiming physical tests or instructor-awarded points that have not actually happened.
