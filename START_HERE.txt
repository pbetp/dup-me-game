DUP ME 4.3 — USE THIS SAME RELEASE ON BOTH COMPUTERS

1. Extract the ZIP into a new folder.
2. Use Python 3.10+ with Tkinter. Install the artwork viewer once:
   macOS/Linux: python3 -m pip install -r requirements.txt
   Windows:     py -3 -m pip install -r requirements.txt
3. Run play.py in your IDE, or open a terminal in this folder:
   macOS/Linux: python3 play.py
   Windows:     py -3 play.py

BACKGROUND MUSIC
Arrival at Zenith starts automatically and loops every two minutes.
SETTINGS -> MUSIC controls its volume; 0 turns only the music off.
PIANO VOLUME controls the notes separately. Ctrl+M mutes all audio.
Keep the assets folder with the extracted game. Closing the game stops music.

ONE COMPUTER + AI
SINGLE PLAYER -> nickname -> AI level -> 2 STD rounds -> START.
The private server and AI start automatically.

TWO COMPUTERS
Connect both to the same Wi-Fi or phone hotspot.
A: MULTIPLAYER -> nickname -> HOST A GAME -> 2 STD rounds -> START HOSTING.
B: MULTIPLAYER -> different nickname -> JOIN A GAME -> JOIN.
B finds the host without typing an IP or port.
In the waiting room: B presses I'M READY, then A presses START GAME.
B can click READY again to cancel readiness before the host starts.
Do not also start server.py when using HOST A GAME.

BOSS CO-OP (TWO COMPUTERS)
Both: MULTIPLAYER -> GAME MODE: BOSS CO-OP. A: HOST A GAME. B: JOIN A GAME.
Team up vs THE DISSONANT (80 HP, 8 HP each). Correct key = 1 boss damage,
wrong or missed key = 1 self damage.

FALLBACK
A: waiting room -> SAVE CONNECTION FILE (also available in the dashboard).
Transfer the JSON file to B.
B: MULTIPLAYER -> JOIN A GAME -> LOAD FILE -> select file -> JOIN.
Both machines must still be on a network that permits local TCP traffic.

SERVER
When hosting, open DASHBOARD in the lobby (or SERV in the game).
It appears inside the game window and shows online count and list.
RESET ROOM clears scores and returns players to the waiting room.
B marks ready again, then A starts. Standalone server.py retains RESTART MATCH.
END MATCH ends the match now; the winner is decided by current scores.
EXIT on the game board: the player who exits always LOSES.
Close dashboard = hide it. SERV on the game board reopens it.
Close main host window = stop the server.
